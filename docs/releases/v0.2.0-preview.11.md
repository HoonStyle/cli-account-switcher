# v0.2.0-preview.11

## Fixes / 수정 사항

- Fix packaged-app login opening a terminal with `MODULE_NOT_FOUND` instead of starting official CLI authentication. External Node now uses the extracted login runner, not a virtual path inside `app.asar`.
- Keep the selected account pinned and fail clearly when the extracted login runtime is missing.
- Add regression checks for packaged/development login paths and missing-runtime handling across macOS, Windows and Linux command generation.

- 설치 앱에서 로그인할 때 `MODULE_NOT_FOUND` 오류로 중단되는 문제를 수정했습니다. 일반 Node가 읽을 수 있는 추출된 로그인 실행 파일을 사용합니다.
- 선택한 계정을 유지하며 로그인 실행 파일이 없을 때 명확한 오류를 표시합니다.

## Compatibility / 호환성

- No account-directory, database-schema or task-protocol changes from preview.10.
- Public distribution still uses local usage records. Personal-edition monetary-credit API features are not included in this release.
- Node.js 24+ and separately installed official CLIs are required.
- Optional OpenClaw integration retains preview.10's paired host SDK, Core agent schema 25 and Native V2 requirements. This release does not add compatibility with Native V1.
- macOS universal DMG and Windows x64 setup/portable installers are unsigned. Windows managed task execution remains unsupported. CI command-generation tests do not prove interactive Windows login.

공개판의 기능 범위와 preview.10의 OpenClaw 호환성 조건은 유지됩니다. 개인용 크레딧 API 기능은 포함되지 않습니다.
