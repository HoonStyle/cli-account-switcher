# v0.2.0-preview.10

## Changes / 변경 사항

- Bind answers to the displayed question generation and input version, with atomic consumption and idempotent response receipts. A late answer cannot consume a newer question.
- Route integrated result delivery through one durable host sender. Require an authenticated receipt for the exact task version and destination; recover unknown outcomes by reading receipts, never by blindly resending.
- Retry only confirmed pre-dispatch failures, at most three times across restarts. Keep partial and ambiguous delivery outcomes on hold.
- Pin research capabilities and validate them before execution. Include the bundled MCP research transport in packaged runtime installations.
- Preserve original authority, cancellation, execution ownership and completion custody at the paired OpenClaw boundary.

- 질문의 generation·inputVersion을 확인해 답변을 한 번만 소비하고 늦은 답변을 차단합니다.
- 결과 전송과 실제 전달 확인을 분리하며, 불명확한 전송은 영수증 조회로만 복구합니다.
- 발송 전 실패가 확인된 경우에만 제한적으로 재시도하고, 조사 도구 준비 상태를 실행 전에 검증합니다.

## Upgrade and compatibility / 업데이트와 호환성

- Update the app, installed CLI, task runtime and optional plugin together after active work is idle. Back up their databases and installation before the upgrade. Do not resubmit existing work to perform an upgrade.
- This release uses Switcher database schema **2** and mutation protocol **3**. Downgrading requires restoring a consistent pre-upgrade backup, not just replacing the executable.
- Optional OpenClaw integration requires a matching host SDK exposing `sendSessionBoundMessageBatch`, `readSessionBoundMessageReceipt`, and atomic workflow-injection lifecycle fencing, with Core agent schema **25** and native record **V2**. A Gateway version number alone does not prove compatibility. Unmodified hosts without these capabilities reject new integrated work before model execution; standalone local account switching does not require OpenClaw.
- Application IDs, account profiles and data directories are unchanged. Public and personal editions remain separate.
- Node.js 24+ and separately installed official Claude Code/Codex CLIs are required.

앱·CLI·서비스·플러그인을 함께 업데이트해야 합니다. DB 스키마가 변경되므로 이전 실행 파일만 덮어써서 되돌리지 마세요. 선택형 OpenClaw 연동은 위 SDK 계약을 갖춘 호스트가 필요하며, 일반 계정 전환은 OpenClaw 없이 사용할 수 있습니다.

## Downloads and validation / 다운로드와 검증 범위

- macOS universal DMG for Apple Silicon and Intel; Windows x64 setup and portable executables; `SHA256SUMS.txt` for all three installers.
- Installers are unsigned; macOS is not notarized. Windows managed task execution remains unsupported.
- Isolated verification covers versioned input, delivery, migration, research preflight, runtime/UI and packaged-runtime contracts. The paired host changes passed 401 Core/SDK and 597 Native tests; those host changes are not bundled in the Switcher installers.
- Real-model research and live-channel delivery fault combinations have not been fully verified. Test fixtures and build success do not establish end-to-end production validation.
