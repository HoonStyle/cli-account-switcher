## Changes / 변경 사항

- Fix oversized OpenClaw task responses with compact summaries and version-checked pagination for context, delegated results, and final responses. Long Unicode results can be read without truncation or duplicate payloads.
- Add a read-only OpenClaw activity view alongside managed tasks, with source filters and explicit stale/offline states. An observed run ending is not reported as task completion.
- Add explicit Claude `build-test` execution policy, bounded recovery from preparation failures, and versioned artifact handoff between delegated tasks. Existing tasks do not automatically gain command-execution permission.
- Improve worktree preparation, runner recovery, and separation of execution, review, and delivery states.

- OpenClaw 작업 조회 응답을 요약과 버전 확인이 있는 분할 조회로 나눠 긴 결과가 잘리는 문제를 수정했습니다.
- 관리형 작업과 구분되는 읽기 전용 OpenClaw 활동 보기 및 연결 끊김·이전 기록 표시를 추가했습니다.
- Claude의 명시적 빌드·테스트 실행 정책, 준비 실패의 제한된 재개, 위임 작업 간 버전이 지정된 산출물 전달을 추가했습니다. 기존 작업의 실행 권한은 자동 확대하지 않습니다.
- 작업 공간 준비와 실행 복구, 실행·검토·전달 상태 구분을 보완했습니다.

## Downloads / 다운로드

- macOS universal DMG: Apple Silicon and Intel.
- Windows x64: NSIS setup and portable executable.
- `SHA256SUMS.txt`: checksums for all three installers.

## Compatibility / 호환성

- Preview software. Installers are unsigned; macOS is not notarized.
- Install the official Claude Code / Codex CLIs separately and sign in with your own accounts.
- Claude `build-test` requires macOS, Claude Code 2.1.290+ with the required sandbox/permission flags, and the relevant local SDK. It is opt-in; `edit-only` remains the default.
- Windows managed task execution remains unsupported. Windows basic checks and installer builds do not imply runtime validation.
- OpenClaw activity requires an installed, authenticated OpenClaw CLI. The plugin manifest requires OpenClaw 2026.9.6+; verify compatibility with the installed Gateway API.
- Existing application IDs and data directories are unchanged. Updating does not resubmit or complete existing tasks.
- Usage is based on local records and may be stale. Scriptable widget code and its server are not included.
