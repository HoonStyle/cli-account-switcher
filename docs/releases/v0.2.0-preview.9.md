## Changes / 변경 사항

- Separate versioned input requests from runtime diagnostics. Notify the owning conversation of blocked work; acknowledgment confirms only that exact notice, not task completion or resumption.
- Use durable execution-attempt identity across runtime, plugin and UI. Keep scheduling, execution, coordinator review and result delivery distinct, including recovery and clock rollback.
- Share one bounded query contract. Retrieve full context, delegated results and final responses with revision-bound pagination and SHA256 validation. Large dashboards use previews with explicit full-detail loading and stale-response protection.
- Check mutation protocol compatibility on the same connection before dispatch. Preserve split UTF-8 output; reject malformed output instead of marking corrupted results successful.
- Show the latest task events and all artifact paths. Make first-time Claude usage-hook setup atomic while preserving existing settings, permissions and symlinks.

- 입력 요청과 실행 진단을 분리하고 요청별 버전·소유권을 확인합니다. 알림 수령 확인이 작업 완료나 재개로 처리되지 않습니다.
- 메인·서브·화면에서 같은 실행 ID를 사용하며 실행·검토·전달 상태를 별도로 관리합니다.
- 대용량 조회를 서버에서 분할하고, 같은 버전의 원문 전체를 복원해 해시로 검증합니다. 화면의 요약과 전체 결과를 구분하고 늦게 도착한 응답을 차단합니다.
- 변경 요청의 프로토콜 호환성을 실행 전에 검사하고, 한글·이모지 출력 손상을 성공 결과로 처리하지 않습니다.
- 최신 작업 이력과 전체 산출물 경로를 표시하며, 새 Claude 설정의 사용량 훅 설치와 기존 설정 보존을 보완했습니다.

## Upgrade and compatibility / 업데이트와 호환성

- Update the app/installed CLI, task runtime and optional OpenClaw plugin together. Stop and replace the task runtime only after active work is idle; do not kill running tasks or resubmit them to upgrade.
- A new client refuses mutations against an incompatible old runtime. Read-only legacy diagnosis remains available where supported. Follow the reported runtime-update requirement instead of retrying the operation.
- Application IDs and data directories are unchanged. The public distribution remains separate from personal installations.
- Node.js 24+ is required. Install the official Claude Code / Codex CLIs separately and use your own accounts.
- Installers remain unsigned; macOS is not notarized. Windows managed task execution remains unsupported; Windows basic checks and packaging do not imply runtime validation.
- The OpenClaw manifest requires Gateway 2026.9.6+; compatibility with the installed Gateway API must also be verified.
- Local verification: all 33 public test programs passed on macOS. Tests use isolated fixture accounts and fake provider processes, not live model requests.
