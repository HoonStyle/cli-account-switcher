# v0.2.0-preview.19

## Changed: compact panel fits on one screen

With more accounts the compact panel no longer fit on a 1080p display (about 1,960 px of content against a 760 px cap). The compact density is now one line per account and the panel is wider:

- Compact panel width 440 → 560 CSS px (comfortable stays 440). Panel height cap 760 → 1000 CSS px, still limited to the work area minus 16 px. With 2 Claude, 4 Codex, 1 EXAONE and Antigravity (2 saved, 3 shared groups) the content is 866 px.
- Each Claude/Codex row keeps name, plan and email on the left and both quota windows on the right. The Codex resource line holds general credits, reset-credit count, nearest expiry (M/D HH:mm), the auto-use marker and the 조회 / 지금 사용 buttons. Below 500 CSS px the email moves to the tooltip and the reset actions to the `…` menu; below 370 px quotas wrap to a second line as before.
- Section titles share a line with **계정 추가**; descriptive hints are hidden in compact. The account count moved into the header.
- Antigravity shows the shared usage first, then the checked login, saved accounts, and save/check controls on one line.
- Section order: Claude Code, Codex, Antigravity, EXAONE API, Gemini API. An API-key category without accounts is hidden; add one from the settings menu (`Gemini API 계정 추가…`).
- API-key Codex accounts no longer show an empty credits/reset-credit cell.

## New: spend and estimated balance for API-key accounts

Plain API keys cannot read billing data on either platform, and neither platform exposes a prepaid balance through an API (Anthropic closed the request for one, anthropics/claude-code#47574, as not planned). API-key rows now show two slots: this month's spend and, for Claude, an estimated balance.

### This machine's Claude Code spend (no admin key needed)

- The statusline hook (settings → `Claude 사용량 수집 (statusline)`) now also records Claude Code's own `cost.total_cost_usd` per session: only the increase, in 10-minute UTC buckets, in `<config>/switcher-spend/<session>.json` (0600). No prompt, path or other payload field is kept. Rate-limit caching is unchanged.
- API-key Claude rows show `<month>월 사용 $x.xx · 이 PC`, summed across that profile's sessions on this machine. Other machines and direct API calls are not included.
- **잔액 입력** stores the balance shown on the Console Billing page with the time it was entered (`<data>/spend/balance.json`, 0600). The row then shows `잔액≈ $y`: the entered balance minus this machine's Claude Code spend since then. The tooltip states the formula and what it leaves out; re-enter it from Billing now and then.

### Organization spend with an admin key

API-key accounts can also register a separate admin key to show this month's organization spend:

- Claude: Anthropic Admin API key (`sk-ant-admin…`), `GET /v1/organizations/cost_report` (USD cents summed over UTC days of the current month).
- Codex: OpenAI Admin key (`sk-admin-…`), `GET /v1/organization/costs` (USD).
- Row shows `<month>월 사용 $x.xx` with its age; without an admin key a **사용 금액 연결** button opens the key entry. Menu: 관리자 키 등록/변경, 사용 금액 지금 조회, 관리자 키 제거.
- Refreshed when the panel opens and every 30 minutes (at most once per 30 minutes per account), and forced by ⌘R or the menu. Failures keep the last amount and show the error status only; provider error messages are not stored.
- A 403 shows **권한 없음** with the fix in the tooltip. Individual Claude Console accounts cannot use the Admin API at all (`/v1/organizations/me` reports an "Individual Org"); set up an organization first, then create an `sk-ant-admin…` key. While the organization lookup fails, the row falls back to this machine's spend.
- Usage in API-key Claude rows prefers the organization total; this machine's total is the fallback.
- Admin keys are stored 0600 under `<data>/api-keys/admin/<tool>/<profile>`, never accepted on argv, never placed in state, snapshots or logs (masked tail only), and removed with the profile.
