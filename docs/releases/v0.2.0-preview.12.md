# v0.2.0-preview.12

## Fixes / 수정 사항

- Add `delegate claude|codex --profile <id> -- ...` for explicit per-process account delegation. A profile is required; missing or unknown profiles fail before launching the official CLI.
- Add `list --json` with installation identity, data root, exact profile IDs and active-account status so agents can distinguish personal and distribution installations.
- Clarify OpenClaw account routing and report the connected installation. Requests must not change the global active account, silently substitute another account or invent managed task IDs for direct CLI runs.
- Preserve official CLI output and exit status. The existing `run <tool> --profile <id> -- ...` route remains compatible.
- Add repository instructions for Claude Code and Codex and isolated source/installed-launcher regression coverage for both tools.

- Claude·Codex에 특정 계정으로 작업을 맡기는 `delegate` 명령을 추가했습니다. 프로필 누락·잘못된 프로필은 실행 전에 거부합니다.
- 설치본과 계정 ID를 확인하는 `list --json` 및 OpenClaw 연결 정보를 보강했습니다. 전역 활성 계정은 변경하지 않습니다.

## Verification / 검증 범위

- Source and installed-launcher delegation tests cover both tools, profile pinning, invalid profiles, child failure propagation and unchanged global active accounts.
- Local live smoke checks and independent natural-language request checks successfully invoked a pinned Codex account and Claude default and collected their responses without changing active accounts. These checks cover direct CLI delegation, not the complete managed-task lifecycle.

## Compatibility / 호환성

- No account-directory, database-schema or task-protocol changes from preview.11.
- Personal and distribution profile stores remain separate. Public builds do not include personal-edition monetary-credit API features or the local personal UI redesign.
- Node.js 24+ and separately installed official CLIs are required.
- Optional OpenClaw integration retains preview.10's paired host SDK, Core agent schema 25 and Native V2 requirements.
- macOS universal DMG and Windows x64 setup/portable installers are unsigned. Windows managed task execution remains unsupported.
