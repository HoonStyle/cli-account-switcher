# v0.2.0-preview.15

## Supersedes withdrawn preview.14

Preview.14 was withdrawn after follow-up CI exposed a macOS process-group exit race. It was not applied to the maintained Studio installation. This release distinguishes zombie-only groups from live permission-denied groups, preserving the original cancellation signal after cleanup. The regression suite reproduces the Darwin kernel behavior directly; live permission failures and failed state probes still fail rather than being ignored.

## Fixes and improvements

- Stop profile-pinned noninteractive delegations from holding a caller session open after the CLI or its immediate caller has exited. On macOS/Linux, clean up the owned process group with bounded TERM/KILL handling while preserving normal output and exit signals.
- Detect leftover descendants separately from the CLI exit in managed runs, record forced cleanup as `orphaned_descendants`, and release the account slot only after owned processes have exited. A quiet live CLI is not a failure; managed tasks may intentionally survive normal coordinator turns or service restarts.
- Fix Windows Claude/Codex login terminal command quoting, including installation paths containing spaces or Unicode and the selected installation root.
- Include opt-in, per-account reset-credit use before expiry with audit logs, stable credit identity/idempotency, and at most three requests spaced at least one minute apart. Existing settings remain in place; no option is enabled by this update.
- Add process-lifecycle, Windows terminal, reset-credit and account-delegation regression coverage using isolated fixtures rather than live account actions.

## Scope and compatibility

- Existing accounts, authentication, active selection, task results and data directories are preserved. No Gateway reconfiguration is required.
- Lifecycle cleanup covers owned process groups on macOS/Linux. Descendants that deliberately escape that group, an uncatchable kill of the direct wrapper itself, and Windows process-tree cleanup are not claimed as covered.
- Windows installers support the account app; managed task execution on Windows remains unsupported.
- These preview installers are unsigned. The release includes SHA256SUMS.txt for the published asset names.

## Public distribution

- Uses `.cli-accounts-distribution`, separately from the personal edition. Direct usage APIs and credential metadata inspection remain disabled.
- Source is exported through an explicit allowlist with edition-specific branding; personal repository history, review reports and account data are not included.
